# ATM — Automated Transaction Mechanics

Odoo module for scheduled JSON exchange of contacts, products, orders,
invoices and payments with an external accounting or ERP system.

Each Odoo version lives on its own branch:

| Branch | Odoo |
| ------ | ---- |
| `19.0` | 19.0 |
| `18.0` | 18.0 |
| `17.0` | 17.0 |
| `16.0` | 16.0 |

The module itself is in [`atm/`](atm/) — see its
[README](atm/README.md) for the file format and the settings, and
[CHANGELOG.md](CHANGELOG.md) for what changed between versions.

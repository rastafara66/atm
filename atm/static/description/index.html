How it works / Як це працює

Odoo writes the documents into a shared directory and reads back whatever the other system puts there. Built for keeping Odoo alongside another accounting system — including 1C and BAS, which exchange through files the same way, so the bridge needs no rework on that side. — Odoo складає документи у спільну теку й читає звідти те, що поклала інша система. Так само обмінюються 1С і BAS, тому міст будується без переробки того боку.

Why files

  • No open port, no middleware, no API keys — nothing to expose
  • Matched by external id, not by database number, so re-importing the same file never duplicates anything
  • Imported documents are created as drafts; posted documents are never overwritten

Чому файли

  • Без відкритих портів, проміжних сервісів і ключів API
  • Зіставлення за зовнішнім ідентифікатором, а не за номером у базі — повторне завантаження того самого файлу нічого не задвоює
  • Завантажені документи — чернетки; проведені ніколи не переписуються
  • Інтерфейс і документація доступні українською

Keep Odoo and your accounting system in step

Through plain JSON files — no open port, no middleware, no API keys

Version 19.0.2.5.0 · LGPL-3 · Odoo 19

How it works

Odoo writes the documents into a shared directory and reads back whatever the other system puts there. Built for keeping Odoo alongside another accounting system — including 1C and BAS, which exchange through files the same way, so the bridge needs no rework on that side.

Why files

  • No open port, no middleware, no API keys — nothing to expose
  • Matched by external id, not by database number, so re-importing the same file never duplicates anything
  • Imported documents are created as drafts; posted documents are never overwritten
  • Interface and documentation in English and Ukrainian

LGPL-3 · Odoo 19

Як це працює

Odoo складає документи у спільну теку й читає звідти те, що поклала інша система. Зроблено, щоб Odoo працювала поруч з іншою обліковою програмою, — зокрема з 1С і BAS, які обмінюються файлами так само, тож міст будується без переробки того боку.

Чому файли

  • Без відкритих портів, проміжних сервісів і ключів API — нічого не треба виставляти назовні
  • Зіставлення за зовнішнім ідентифікатором, а не за номером у базі — повторне завантаження того самого файлу нічого не задвоює
  • Завантажені документи створюються чернетками; проведені ніколи не переписуються
  • Інтерфейс і документація — українською та англійською

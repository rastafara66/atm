## 19.0.2.3.0 — 2026-09-05

### Added

- Version check.
- Once a day a scheduled action asks which version is current, and a newer one is announced on the exchange log record and in the settings.
- The request is a bare GET: no install id, no database name, not even the version you are running — only which series to answer for.
- The version check covers the 1C / BAS Connector as well.
